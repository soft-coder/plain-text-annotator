# plain-text-annotator
Plain Text Annotator - a tool for adding annotations to plain text files.


## Задание: Приложение для аннотации текста
Разработайте одностраничное приложение (SPA) с использованием Angular18+, которое позволяет пользователю создавать и редактировать статьи (является простым текстом), а также выделять и аннотировать текст в них. Все данные (статьи, аннотации и т.д.) хранятся в localStorage, эмулируя работу с мок-сервером.

### Цели приложения

* CRUD для статей:
    * Создание статьи (текст без форматирования и изображений):
        * Редактирование статьи
        * Удаление статьи
        * Просмотр списка доступных статей и выбор одной для просмотра/редактирования
    * Аннотирование текста:
        * Возможность выделить произвольный фрагмент текста и назначить ему цвет и аннотацию(текстовое примечание).
        * Подчёркивание выделенного текста выбранным цветом.
        * При наведении курсора на выделенный текст должна всплывать аннотация (tooltip или аналогичный механизм).
        * Все аннотации должны сохраняться вlocalStorage и быть восстановлены при повторном открытии статьи.
    * Без сторонних библиотек:
        * Не использовать сторонние библиотеки для UI, аннотаций, хранения данных и всплывающих подсказок (всё реализовать средствами Angular, HTML, CSS и встроенных API браузера).

### Технические требования

* Framework: Angular 18+
* Язык: TypeScript
* Стили: CSS/SCSS (на усмотрение разработчика)
* Архитектура:
    * Соблюдение принципов разделения ответственности (например, компоненты, сервисы)
    * Использование реактивных подходов (RxJS) приветствуется

### Критерии оценки
* Чистота и читаемость кода
* Соответствие требованиям
* Удобство UX/UI
* Структура проекта (модули, компоненты, сервисы)
* Использование Angular-специфичных подходов (сервисы, DI, компоненты, реактивность и т.д.)
* Работа с DOM без сторонних библиотек
* Реализация подсветки и аннотаций средствами DOM (например, с помощью Range API)
